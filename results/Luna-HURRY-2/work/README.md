# Figure generation

The six PNG figures are generated by `make_figures.py` with the supplied CSV files. The script uses Python from `/opt/anaconda3/envs/p314/bin/python`, pandas for data processing, and Matplotlib for plotting. No packages were installed.

From this run directory, regenerate the figures with:

```sh
MPLCONFIGDIR=work/.mplconfig /opt/anaconda3/envs/p314/bin/python work/make_figures.py
```

The script writes to `answers/figures/`. It reads the World Bank and Our World in Data life-expectancy files plus the county-level Census file. There are no manual production steps.
