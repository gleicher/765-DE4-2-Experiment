# Figure generation

The six PNGs in `answers/figures/` are generated by `work/make_figures.py`. The script reads only the supplied CSV files in `data/`, writes small derived tables to `work/derived/`, and saves the figures to `answers/figures/`.

Use the curated Python environment and run from this folder:

```sh
MPLCONFIGDIR=/private/tmp/p314-mpl-cache \
  /opt/anaconda3/envs/p314/bin/python work/make_figures.py
```

The script uses pandas and Matplotlib, already installed in `p314`; it does not install packages or create an environment. It reads the county census file as comma-separated Windows-1252 text and the state aggregate file as tab-separated Windows-1252 text. No Tableau workbook or manual figure editing is required. For the Canvas response, upload each PNG linked from `answers/answer.md`.
