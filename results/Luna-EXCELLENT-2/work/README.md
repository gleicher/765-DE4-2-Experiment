# Figure source and regeneration

The six static PNG figures are generated by `make_figures.py` from the course-provided World Bank life-expectancy and USDA county files. It uses Python 3.14 from `/opt/anaconda3/envs/p314/bin/python` with pandas, NumPy, and Matplotlib. No packages were installed and no outside data was joined.

From this run directory, regenerate the figures with:

```sh
MPLCONFIGDIR="$PWD/work/mplconfig" /opt/anaconda3/envs/p314/bin/python work/make_figures.py
```

The script writes or overwrites the six PNGs in `answers/figures/`. There are no manual figure-editing steps. Review the images after regeneration, then upload them separately for the Canvas image questions. `contact-sheet.png` is a working preview of the figures.
