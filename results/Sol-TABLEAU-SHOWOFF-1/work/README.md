# Reproducing this instructor example

Actual tools: OpenAI Codex; Python 3.14 from the existing p314 environment; pandas, NumPy, Matplotlib, Pillow (output integrity checks); shell file tools and local image inspection. Tableau was not used. No packages were installed, and no external pages were opened.

From this run's root directory:

```sh
/opt/anaconda3/envs/p314/bin/python work/make_figures.py
```

This writes six PNGs to `answers/figures/` and processed CSVs here. The script sets its Matplotlib cache to `work/mplconfig/`. No manual graphics edits are required. Written answers and the critique are in `answers/answer.md`; they are not generated by the script.

All source data remains in `data/`. The county source uses commas and Windows-1252 text encoding, while the state source uses tabs. The script explicitly selects G7 countries for 2019–2023, Japan/South Korea by sex for 1960–2023, complete U.S. county records excluding Puerto Rico for 2023, and the 50 states for 2007–2023. County scatter axes omit 12 extreme points from view, with omitted counts stated on the figure; all 3,106 eligible counties contribute to the percentage bars.

Designs use standard line panes, change bars, percentage stacks, circle scatterplots, and a highlight table. Equivalent Tableau construction: place relevant dimensions on rows/columns; filter year/country; calculate 2019 baseline differences; assign category to color; count counties and use percent of total within group; use fixed axes/reference lines; pivot state year measures into Year and Rate for the highlight table. A threshold line can be a second mark layer with `Threshold = -[Natural Change Rate]`, filtered to negative natural change.

Run `/opt/anaconda3/envs/p314/bin/python work/validate_outputs.py` to check unique source keys, group denominators, clipped counts, state matrix completeness, PNG integrity, and coverage of all 20 Canvas questions.
