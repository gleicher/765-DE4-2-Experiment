# Figure generation

The six static figures for `answers/answer.md` are generated by `generate_figures.py`.

From this run directory, run:

```sh
MPLCONFIGDIR=work/mplconfig /opt/anaconda3/envs/p314/bin/python work/generate_figures.py
```

The script reads the course-provided files in `data/` and writes PNGs to
`answers/figures/`. It uses Python 3.14, pandas, and Matplotlib from the existing
`p314` environment. The census CSV is read as Windows-1252 because a few supplied
county names use that encoding. The script filters Puerto Rico from the census
plots because the supplied file has no matching 2023 migration-rate values there.

There are no manual editing steps. The figures include their own titles, labels,
captions, and data-source notes. No external pages were opened.
