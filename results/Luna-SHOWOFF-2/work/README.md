# Figure source and regeneration

The six figures are generated by `make_figures.py` with Python from the shared `p314` environment. The script uses the already-installed pandas and Matplotlib packages and reads only the CSV files in `../data/`. Pillow was used separately to assemble a contact sheet for manual layout review.

From this directory, regenerate the PNGs with:

```sh
/opt/anaconda3/envs/p314/bin/python make_figures.py
```

The script writes the output to `../answers/figures/`. It creates a local Matplotlib cache in `work/mplconfig/`. No packages were installed. There are no manual editing steps. `contact-sheet.png` is a Pillow-generated preview used to inspect the layouts; it is not part of the submission figures.
