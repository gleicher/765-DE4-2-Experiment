# Figure generation

The six PNG figures in `answers/figures/` are generated by `generate_figures.py`.
From this folder, run:

```sh
/opt/anaconda3/envs/p314/bin/python work/generate_figures.py
```

The script uses the existing `p314` Python environment with pandas, NumPy, and
Matplotlib. It reads the provided data in `data/` and writes the figures to
`answers/figures/`. No packages need to be installed.

The life expectancy script pairs male and female records by entity and year,
calculates the female-minus-male gap, and summarizes the yearly distribution.
The Census steps select complete cases for each figure, group counties using
the 2023 Rural-urban Continuum Code (1–3 metro; 4–9 nonmetro), and compute the
county-level summaries shown in the captions. The scatter plot adds simple
linear fits and correlations; the binned alternate uses median income and its
25th–75th percentile range. Migration uses the dataset’s supplied 2023 rate
fields; unemployment uses annual medians and interquartile ranges.

The full Census CSV is comma-delimited and uses Windows-1252 text encoding, so
the script reads it with those settings. The local data README says the full
file is tab-separated; the file itself is comma-delimited. No manual figure
editing or other manual processing is required after generation.
